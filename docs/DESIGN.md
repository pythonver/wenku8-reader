# 轻小说文库 — 设计基调（DESIGN.md）

> 样式基调规范 · v1.0 · 2026-09-08
> 全量重写工程：`wenku8-reader`（Compose + Material3）
> 配套实现：`app/src/main/java/com/wenku8/reader/core/designsystem/theme/*`

---

## 0. 设计哲学

**"内容为王，界面退让。"**

这是一个阅读器。阅读体验优先于一切：UI 元素低存在感、可唤起、可隐藏；应用壳层与阅读器保持同一冷调美学——充足留白、克制的信息层级、流畅而不喧宾夺主的动效。一切设计决策围绕两件事：**让正文更易读**、**让沉浸不被打破**。

风格锚点：Apple Books / Kindle 的克制感 + 冷调科技感。

## 1. 色彩

### 1.1 品牌冷蓝/青（演进自旧版品牌蓝 `#4284F5`）

| Token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 主蓝 `brand` | `#3B6EF6` | `#7C9CFF` | 品牌点、选中态、主操作 |
| 青 `accent` | `#00B8D4` | `#00B8D4` | 进度、高亮、强调 |

**规则：阅读正文绝不用品牌色。** 品牌色只出现在壳层（按钮/进度/选中/Logo）。

### 1.2 中性色（阅读与内容主体）

| 语义 | 浅色 | 深色 |
|---|---|---|
| background | `#FAFAFA` | `#0F1115` |
| surface | `#FFFFFF` | `#17191D` |
| 文字 primary | `#17181A` | `#E8EAED` |
| 文字 secondary | `#5A5D63` | `#A2A6AD` |
| 文字 disabled | `#9A9DA3` | `#5F6368` |

### 1.3 语义色
成功 `#2E9E5B` / 警告 `#E6A23C` / 错误 `#E05252` / 信息 `#3B6EF6`（低饱和，不抢主色）。

### 1.4 阅读器四色（独立于应用主题）

| 模式 | 背景 | 正文 | 次要文字 |
|---|---|---|---|
| Day 白天 | `#F7F6F2` 微暖白 | `#202124` | `#5F6368` |
| Night 夜间 | `#121212` | `#B9B9B9` | `#7A7E85` |
| Sepia 羊皮纸 | `#CFBEB6`（沿用旧值） | `#4A4038` | `#8A7568` |
| Green 护眼绿 | `#C7EDCC` | `#2D3B2F` | `#5C7A60` |

阅读器四色通过 `LocalReaderColors` CompositionLocal 提供，不随系统明暗变化。

## 2. 字体（Typography）

- **UI 层**：系统无衬线（Roboto），层级 token：Display/Headline/Title/Body/Label。
- **正文/阅读器**：**中文衬线**。实现取 `FontFamily.Serif`（设备解析为 Noto Serif CJK / 宋体系）；后续可在 `assets/fonts` 打包 Noto Serif SC 无感替换。
- **阅读器正文多档**：12–28sp，默认 18sp（沿用旧版默认）；行高 1.8、段距、**首行缩进 2 字符**（`　　`）、两端对齐、字距 0.2sp。

---

## 3. 形状 / 间距 / 图标

- **圆角**：卡片 `12/16dp`；**阅读界面圆角 ≈ 0**（全出血、沉浸）。
- **间距**：4dp 网格（`4/8/12/16/24/32/48`）；壳层页面边距 ≥16dp；阅读正文左右 ≥20dp。
- **图标**：Material Symbols（Outlined/Rounded），统一描边风格。
- **App 图标**：自适应图标——品牌蓝底 + 白色翻开的书（`res/drawable/ic_launcher_foreground.xml`）。

---

## 4. 动效（Motion）

统一语言：**短促 + 非线性**（spring / emphasized easing），主反馈 ≤300ms。

| 场景 | 动效 |
|---|---|
| 页面转场 | 水平滑入 + 淡入；阅读器返回下滑 |
| 列表 | LazyColumn 条目交错淡入/上移（offset 分层） |
| 阅读器翻页 | 水平滑动 + 轻微视差（可选仿真卷曲）；E-ink 模式关动画 |
| 启动 | Lottie 品牌动画 → 主界面淡入 |
| 交互反馈 | 按压波纹、对话框 spring 弹入、Snackbar 滑入 |

## 5. 页面基调

### 5.1 壳层（首页/搜索/详情/我的小说）
- 冷白/冷黑背景，充足留白；卡片用 `surface` + `12dp` 圆角 + 轻阴影
- 主操作按钮：品牌蓝实底；次操作：幽灵/文本按钮
- 列表行：封面（`RoundedCornerShape(8dp)`）+ 书名（衬线或 `titleMedium`）+ 作者/元信息（`bodySmall` 次要色）

### 5.2 阅读器（核心屏）
- **全屏沉浸**：状态栏/导航栏隐藏或透明
- **唤出式工具栏**：轻点唤出顶栏（章节名/书签/返回）+ 底栏（目录/设置/页级进度）
- 底部细进度条：本章页进度 + 全书进度，青 `#00B8D4` 点亮
- 设置抽屉：背景四色（切换带动画过渡）、字号、行距、翻页方式、E-ink
- 章节切换：左右翻页手势 + 章末自动接续

---

## 6. 关键数据设计决策（影响视觉展示）

- **页级进度**：页码是渲染产物（随字号/旋转/设置变化），**不存页码**。存稳定锚点 `(cid, elementIndex, charOffset)`，渲染时按当前设置分页定位推导页码用于显示。
- **书签**：`(aid, vid, cid, elementIndex, charOffset, name, note, excerpt, createdAt)`——可命名 + 备注，列表按小说分组展示（章节名 + 摘录 + 时间）。
